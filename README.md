# Latent representation for PDE surrogates: POD vs. convolutional autoencoder

Code, data-generation scripts, analysis scripts, and logs for the paper
"Faithfulness Before Accuracy: Choosing a Latent Representation for PDE Surrogates."

The study compares POD and a convolutional autoencoder (AE) on single-phase
Darcy-flow pressure fields generated by a custom OpenFOAM solver, at matched
latent dimension n = 8, 16, 32, 64. Three experiments:

- **A (fixed well):** the well stays at the domain centre.
- **B (variable well):** the well centre is drawn uniformly over the domain.
- **C (dose response):** the well offset is drawn from [-R, R] cells for
  R in {250, 500, 1000, 1500, 3000} m; R = 0 is Experiment A.

Placeholders used in scripts and logs (replace before running):

- `<DATA_ROOT>`: the working directory holding the ensembles (e.g. `/work/<user>`).
- `<HOME>`: the home directory (e.g. `/home/<user>`).
- `<ENV>`: the Python virtual environment with numpy, scikit-learn, scipy and matplotlib.
- `<ACCOUNT>`: the Slurm account.

## Requirements

- OpenFOAM v2212, with `darcyFoam` compiled from `solver/darcyFoam` (`wmake`).
- Python 3 with numpy, scikit-learn, scipy, matplotlib and torch (see `requirements.txt`).
- Slurm. Jobs use partition `workq` and an account that you must set (`<ACCOUNT>`).
  The cluster rejects `--mem`; the scripts do not set it.

## Data generation

Each sample is one 500-day trajectory on a 40 x 40 x 20 mesh (32,000 cells) of a
10 km x 10 km x 100 m domain. The top 8 and bottom 12 layers have different rock
statistics. Snapshots are written every 5 days (100 per run).

Per-sample randomness, in order:

1. Permeability: log-normal, correlated Gaussian noise (Fourier filter,
   correlation length 0.25 cells), layer-dependent mean and clipping.
2. Porosity: 0.6 times the permeability noise plus 0.4 times an independent field.
3. Compressibility: linear in porosity, mapped from [0.05, 0.25] to
   [0.7, 1.3] x 10^-9 Pa^-1.
4. Well location (Experiments B and C only).

The well-zone radius is 200 m and its permeability is 10 D. The well rate is
constant in time in all reported experiments. The rate-step ("event") mechanism
in the general generator is neutralized: `rate_multiplier` is fixed at 1.0 and
`wellRate_before == wellRate_after`.

The radius generator takes `--radius R` (a multiple of 250 m) and `--seed`. The
offset is drawn from a separate RNG seeded with `--well-seed` (default 12345), so
the rock fields are identical to the fixed-well run for the same `--seed`.

## Analysis protocol

- **Split:** 1000 wells per condition; 850 for training, 150 held out (15%). The
  split is by well: all time steps of a well are on the same side. The seed
  controls the split, randomized SVD, AE initialization, validation split and
  minibatch order.
- **Validation:** for the AE, validation uses a random subset of *snapshots*
  (not wells). Early stopping and checkpoint selection use this subset only; test
  wells are never used for training or selection.
- **POD:** randomized SVD (scikit-learn) of the centred training snapshots.
- **AE:** convolutional encoder (20 vertical layers as channels, 40 -> 20 -> 10 -> 5,
  channels 32/64/64, stride 2), linear bottleneck to n, mirrored transposed-
  convolution decoder, ReLU. Adam (lr 1e-3), ReduceLROnPlateau (factor 0.5,
  patience 8), batch size 256, per-grid-cell standardization. Early stopping with
  patience 20, minimum 40 epochs, cap at 500 epochs; the best-validation
  checkpoint is kept.
- **Error metric:** eta = ||X_test - X_hat||_F / ||X_test||_F over the whole
  held-out matrix, one value per model.
- **Gap:** gap = 100 (eta_POD - eta_AE) / eta_POD (%). Positive favours the AE.
- **Verdict:** a tie is declared when the sign of the gap is not the same across
  all seeds (`aggregate_seeds.py`).
- **Truncation error:** eps_n = (1 - sum_{i<=n} sigma_i^2 / ||X_tr - mean||_F^2)^{1/2}
  (`plot_singular_values.py`). The denominator is the total squared norm over all
  training snapshots, computed before the randomized SVD.

### Epoch cap

Under the 500-epoch cap, 18 of the 40 AE fits (A: 8/20, B: 10/20) reached the cap
before early stopping. For a run that stopped early, `n_epochs_run = best_epoch + 20`;
a run that hit the cap has `n_epochs_run = 500` and no early stop. The paper reports
this truncation and does not change the results.

## Running on the cluster

Edit the placeholders in `slurm/*.sbatch` (or make a run copy with the paths
filled in, and do not commit it) before submitting.

1. **Build the solver:** `cd solver/darcyFoam && wmake`.
2. **Generate the ensembles:**
   - `slurm/ch3_fixedwell_sweep.sbatch` (A);
   - `slurm/ch3_full_sweep.sbatch` (B);
   - `slurm/darcyFoam_v3_radius.sbatch` with `R=<value>` (Experiment C, 5 radii);
     it runs `generate_samples_v3_radius.py --seed 0`.
3. **Extract fields** with `extraction/extract_fields_v3.py`.
4. **Run the fits:**
   - `slurm/run_seeds.sbatch`: array 0-9 (indices 0-4 Experiment A, 5-9 Experiment B);
   - `slurm/run_dose.sbatch`: array 0-14 (5 radii x 3 seeds).
5. **Truncation error and spectra:**
   - `slurm/plot_singular_values.sbatch` for A and B (both conditions);
   - `slurm/plot_singular_values_dose.sbatch` for each dose level (array 0-4 for
     R = 250, 500, 1000, 1500, 3000 m). Each task analyses a single condition, so
     its `.out` file labels the condition "Exp A" even though it is Experiment C;
     the dose level is in the file name.
   - Outputs: `singular_values.npz` / `.pdf` for A and B, and
     `logs/svd_eps_dose_r{R}.npz` / `.pdf` for the dose levels.
6. **Build tables and figures:**
   ```
   python3 analysis/aggregate_seeds.py <DATA_ROOT>/logs/seeds
   python3 analysis/make_full_tables.py
   python3 analysis/plot_dose.py <DATA_ROOT>/logs/dose
   python3 analysis/plot_gap_vs_eps.py        # writes spectrum_gap.pdf
   ```
7. **Drawdown radius:**
   ```
   cd analysis
   python3 -I measure_ell.py --data <DATA_ROOT>/ldo_data_v3_fixedwell --n 200
   ```
   Output: `logs/measure_ell_output.txt`. Values at days 5, 50, 250 and 500 are
   616, 923, 1234 and 1297 m (200 samples). The paper uses ℓ = 1200 m as a
   convention (within 3% of the day-250 value).

## Truncation error, computed values

Seed 0, from `plot_singular_values.py` (experiment A and the dose levels):

| Condition | eps_8 | eps_16 | eps_32 | eps_64 |
|---|---|---|---|---|
| A (R = 0) | 0.0237 | 0.0186 | 0.0145 | 0.0107 |
| R = 250 m | 0.0719 | 0.0253 | 0.0154 | 0.0111 |
| R = 500 m | 0.1121 | 0.0518 | 0.0230 | 0.0113 |
| R = 1000 m | 0.1858 | 0.0770 | 0.0413 | 0.0215 |
| R = 1500 m | 0.2254 | 0.1097 | 0.0488 | 0.0297 |
| R = 3000 m | 0.3097 | 0.1872 | 0.0994 | 0.0437 |

Across the 28 (condition, n) pairs, the Spearman correlation between eps_n and the
seed-mean gap is 0.973. A single threshold between 0.020 and 0.021 gives the sign
of the gap correctly for 27 of 28 pairs; the exception is A at n = 8. The threshold
is fitted in sample.

## Logs and results: read before use

- `logs/<job>_<task>_podae_*.out` are the authoritative records of each fit.
- `logs/seeds/results_{A,B}_seed{0..4}.json` were **rebuilt from the `.out` logs**
  for the B group, because the original JSON writes exceeded the file quota. Those
  files contain `"rebuilt_from_log"`. Their `ae_diagnostics` fields do **not** match
  the logs and must not be used. Epoch-cap counts were computed from the `.out` logs.
- `logs/dose/results_r{R}_seed{s}.json` (Experiment C): keys `n_train_snapshots`,
  `n_test_snapshots`, `held_out_frac`, `results`, `ae_diagnostics`.
- `logs/seeds_drawdown/TEST_*.json` are smoke tests (50 samples, 2 epochs). Not for
  reporting.
- `logs/measure_ell_output.txt`: output of `measure_ell.py` (fixed-well ensemble).
- `logs/svd_eps_dose_r{R}.npz`, `singular_values.npz`: SVD outputs (see above).

## Known limitations

- One PDE, one source of geometric variation (a single translating well), one
  structure scale, one AE architecture and training protocol, projection error only.
- No comparison with translation-aligned linear methods (shifted POD, registration).
- The random-field correlation length (0.25 cells) gives a nearly cell-uncorrelated
  field (lag-one correlation about 0.06). This is disclosed in the manuscript and
  has not been varied.
- The AE is trained under a 500-epoch cap that truncates 18 of 40 fits.
- The truncation-error threshold is fitted in sample and not validated on held-out
  conditions.
- The drawdown-relative error (eta_drawdown = ||X - X_hat|| / ||X - x0||, with x0 the
  kinematic initial pressure) is implemented in `analysis/pod_vs_ae_eta_dd.py`, but
  its full run is not yet reported.
